# API

Контракты описаны в OpenAPI 3.1 и открываются в интерактивном виде — Swagger UI
живёт по отдельному адресу и содержит переключатель спецификаций.

[:octicons-link-external-24: Открыть Swagger UI](../swagger/index.html){ .md-button .md-button--primary }

!!! info "Два адреса"

    В режиме разработки Swagger UI поднимается отдельной командой на
    `http://127.0.0.1:8101/`, в собранном портале лежит по пути `/swagger/`.
    Подробности — [Как запустить](../run.md).

## Что внутри

### Основной контракт

`exchange-orders.openapi.yaml` — `POST /v1/exchange-orders` и шесть сопутствующих
эндпоинтов: котировка, подтверждение, статус, отмена, лимиты, справочник активов.
3636 строк, 38 схем, 43 примера, каталог из 30 кодов ошибок.

### Контракты внешних сервисов

Девять машиночитаемых стабов — то, что приложение **получает** от внешних систем.
Их семантика, таймауты, ретраи, вебхуки и поведение при отказе разобраны на
странице [Контракты интеграций](integrations.md).

| Сервис | Спецификация | Зачем нужен заявке на обмен |
|--------|--------------|------------------------------|
| S1 — Users Service | `users.yaml` | Профиль, статус пользователя, резидентство |
| S2 — KYC Service (WebID) | `kyc-webid.yaml` | Уровень верификации, гейт на суммы |
| S3 — Scoring / AML Service | `scoring-aml.yaml` | Риск-скор операции, блокировки |
| S4 — Limits & Fees Service | `limits-fees.yaml` | Дневные и разовые лимиты, расчёт комиссии |
| S5 — Exchange Rate Service | `exchange-rates.yaml` | Котировка, TTL курса |
| S6 — Accounting | `accounting.yaml` | Балансы, холды, проводки |
| S7 — Crypto Provider | `crypto-provider.yaml` | Исполнение крипто-ноги, подтверждения сети |
| S8 — Order Service | `order-service.yaml` | Жизненный цикл заявки, исполнение |
| S9 — Notification Service | `notifications.yaml` | Уведомления о смене статуса |

Все десять спецификаций доступны в выпадающем списке Swagger UI.
