# System Design Brief

Роль:

Senior Solution Architect.

Необходимо подготовить High Level System Design Document.

Опиши архитектуру системы с точки зрения взаимодействия компонентов.

Используй подход C4 Model.

Необходимо описать:

• основные сервисы;

• ответственность каждого сервиса;

• последовательность взаимодействий;

• основные REST API;

• точки отказа;

• обработку ошибок;

• жизненный цикл заявки;

• основные бизнес-проверки;

• предположения по масштабированию.

Не уходи в реализацию БД.

Используй UML Sequence Diagram и Component Diagram в формате Mermaid.

Документ должен быть пригоден для передачи команде разработки.
