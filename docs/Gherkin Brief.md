# Gherkin Brief

Роль:

Senior Business Analyst.

Подготовь Feature-файл.

Используй язык Gherkin.

Необходимо описать:

минимум один Happy Path

и не менее пяти негативных сценариев.

Включи:

Недостаточно средств.

Изменение курса.

Минимальная сумма.

Неверная валютная пара.

Недоступность сервиса курсов.

Просроченный курс.

Некорректная сумма.

Каждый сценарий должен быть написан через:

Given

When

Then

Используй понятный бизнес-язык без технических деталей реализации.
