# Design Brief

## Роль

Ты — Senior Product Designer с опытом проектирования интерфейсов современных финтех-продуктов.

Необходимо разработать концептуальный интерфейс экрана обмена валют для внутреннего цифрового кошелька.

Интерфейс должен выглядеть так, словно он является частью продуктов Revolut, Wise, Coinbase или Stripe Dashboard.

Не используй устаревшие визуальные решения, сложные формы или перегруженные интерфейсы.

---

# Основные принципы

Минимализм.

Максимально понятный пользовательский сценарий.

Высокая визуальная иерархия.

Минимальное количество действий.

Интерфейс должен выглядеть дорого, современно и профессионально.

---

# Компоновка страницы

Используй одну центральную карточку шириной около 440 px.

Карточка располагается по центру страницы.

Внутри карточки элементы должны следовать естественному пользовательскому сценарию сверху вниз.

## Верхняя часть

Заголовок:

Exchange

Подзаголовок:

Convert one currency into another instantly.

Ниже расположен небольшой блок с балансами пользователя.

Каждая валюта отображается отдельной строкой.

Используй небольшие иконки валют.

---

## Блок "You Pay"

Включает:

• выпадающий список выбора валюты;

• большое поле ввода суммы;

• отображение доступного баланса;

• кнопку выбора "MAX";

• быстрые действия 25%, 50%, 75%, 100%.

---

## Между блоками

Расположи круглую кнопку со стрелками обмена.

Она должна визуально выделяться.

После нажатия валюты меняются местами.

Используй плавную анимацию.

---

## Блок "You Receive"

Практически повторяет предыдущий блок.

Поле суммы только для чтения.

Под полем небольшой текст:

Calculated automatically using the current exchange rate.

---

## Exchange Summary

Небольшая карточка.

В две колонки.

Содержит:

Current Rate

Fee

Estimated Receive

Rate Expiration Timer

Network

---

## Нижняя часть

Большая синяя кнопка

Exchange Now

Ширина 100%.

Высота около 48 px.

Под кнопкой небольшой юридический текст серого цвета.

# UX

Автоматический пересчет суммы.

Inline Validation.

Скелетон при загрузке.

Empty State.

Loading State.

Disabled State.

Success State.

Error State.

Кнопка становится активной только после прохождения всех проверок.

Добавь мягкие анимации и микровзаимодействия.

Финальный результат должен выглядеть как готовый экран современного банковского приложения.
