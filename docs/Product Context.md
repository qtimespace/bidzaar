# Product Context

## Общая информация

Разрабатывается внутренний модуль цифрового кошелька пользователя. Пользователь может хранить средства в нескольких валютах и выполнять мгновенный обмен между ними.

В рамках данной задачи необходимо спроектировать только процесс создания заявки на обмен валют. Не рассматриваются вопросы исполнения заявки, интеграции с платежными системами, бухгалтерского учета или хранения истории операций.

Предполагается, что система уже располагает следующими сервисами:

- Wallet Service — хранение и предоставление информации о балансах пользователя.
- Exchange Rate Service — получение актуальных курсов валют.
- Exchange Service — выполнение бизнес-проверок возможности обмена.
- Order Service — регистрация заявки на обмен.

Все сервисы взаимодействуют через REST API.

---

## Цель продукта

Предоставить пользователю максимально простой, безопасный и быстрый способ обменять одну валюту на другую.

Пользователь не должен задумываться о внутренних процессах системы. Интерфейс обязан самостоятельно выполнять все расчеты, отображать актуальную информацию и предотвращать ошибки до момента подтверждения операции.

Основной принцип — одно действие, один экран, одно подтверждение.

---

## Основной сценарий

1. Пользователь открывает экран обмена.
2. Система загружает балансы и актуальные курсы.
3. Пользователь выбирает валютную пару.
4. Пользователь вводит сумму обмена.
5. Система автоматически рассчитывает сумму получения.
6. Пользователь подтверждает операцию.
7. Выполняются проверки.
8. Создается заявка на обмен.
9. Пользователь получает подтверждение успешного создания заявки.
